# 04 Generics
## Knowledge Test
### 1. Describe the problem generics address.
Generics solve the problems of **type safety**, **performance overhead (boxing/unboxing)**, and **code duplication**:
* **Type Safety:** Without generics, non-generic collections (like `ArrayList`) store elements as `object`, allowing any data type to be added. Type mismatch errors are only discovered at runtime. Generics enforce strong typing at compile time.
* **Performance:** Storing value types (e.g., `int`, `struct`) in non-generic collections causes **boxing** (converting value types to `object` on the heap) and **unboxing** (converting `object` back to value type). Generics eliminate boxing/unboxing overhead.
* **Code Reusability:** Generics allow you to write a single algorithm or data structure (e.g., a stack or list) that works with any data type without re-writing type-specific implementations.

### 4. True/False. When a generic class has multiple type parameters, they must all match.
False. Generic classes with multiple parameters don't require matching types. For example:
```csharp
Dictionary<TKey,TValue> sampleDict = new Dictionary<string, int>();
```

### 6. Name two methods that cause items to be removed from a List.
All removal methods: 
* `Clear` : Removes all elements
* `Remove(T item)` : Removes the first occurance of item
* `RemoveAll(Predicate<T> match)` : Removes all elements that match
* `RemoveAt(int index)` : Removes element at `index`
* `RemoveRange(int index, int count)` : Removes `count` elements starting at `index`

### 7. How do you indicate that a class has a generic type parameter?
By following the class name with `<T>`
```csharp
public class myClass<T>
```

---
### 8. True/False. Generic classes can only have one generic type parameter.
False. Generic classes can have any number of generic type parameters.

---
### 9. True/False. Generic type constraints limit what can be used for the generic type.
True. Generic types can be constrained to Value, Reference and Object types
* Value: `where t: struct`
* Reference: `where t: class`
* Object: `where t: new()`

---
### 10. True/False. Constraints let you use the methods of the thing you are constraining to.
True. When generic type parameter is constrained to a class or interface, members (methods & properties) of the class or interface can be called.

### 1. Create a custom Stack class MyStack<T> that can be used with any data type which has following methods:
1. int Count()
2. T Pop()
3. Void Push()
```csharp
public class MyStack<T>
{
    private Element _top;
    private int _count;

    private class Element
    {
        public Element (T value, Element next)
        {
            Value = value;
            Next = next;
        }

        public T Value { get; }
        public Element Next { get;}
    }

    public int Count()
    {
        return _count;
    }

    public T Pop()
    {
        if (count == 0 || _top == null) {
            return default;
        }
        T val = top.Value;
        _top = _top.Next;
        _count--;
        return val;
    }

    public void Push(T val)
    {
        _top = new Element(val, _top);
        _count++;
    }
}
```

### 2. Create a Generic List data structure MyList<T> that can store any data type. Implement the following methods.
1. void Add (T element)
2. T Remove (int index)
3. bool Contains (T element)
4. void Clear ()
5. void InsertAt (T element, int index)
6. void DeleteAt (int index)
7. T Find (int index)
```csharp
public class MyList<T>
{
    private T[] _items;
    private int _count;
    private const int DefaultLength = 4;

    public MyList()
    {
        _items = new T[DefaultLength];
        _count = 0;
    }

    // Helper method to adhere to DRY
    private void CheckCapacity()
    {
        if (_count + 1 > _items.Length)
        {
            int newLength =  _items.Length * 2;
            T[] newArray = new T[newLength];
            Array.Copy(_items, 0, newArray, 0, _count);
            _items = newArray;
        }
    }
    
    public void Add (T element)
    {
        CheckCapacity();
        _items[_count] = element;
        _count++;
    }

    public T Remove (int index)
    {
        if (index < 0 || index >= _count)
        {
            throw new ArgumentOutOfRangeException(nameof(index), "Index is out of range.");
        }

        T removedItem = _items[index];

        for (int i = index; i < _count -1 ; i++)
        {
            _items[i] = _items[i + 1];
        }

        _count--;
        _items[_count] = default;
        return removedItem;
    }

    public bool Contains (T element)
    {
        for(int i = 0; i < _count; i++)
        {
            if (EqualityComparer<T>.Default.Equals(_items[i], element)){
                return true;
            }
        }
        return false;
    }
    public void Clear ()
    {
        _items = new T[DefaultLength];
        _count = 0;
    }
    public void InsertAt (T element, int index)
    {
        if (index < 0 || index >= _count)
        {
            throw new ArgumentOutOfRangeException(nameof(index), "Index is out of range.");
        }
        
        CheckCapacity();

        for (int i = _count; i > index; i--)
        {
            _items[i] = _items[i - 1];
        }

        _items[index] = element;
        _count++;
    }
    public void DeleteAt (int index)
    {
        Remove(index);
    }
    public T Find (int index)
    {
        if (index < 0 || index >= _count)
        {
            throw new ArgumentOutOfRangeException(nameof(index), "Index is out of range.");
        }

        return _items[index];
    }
}
```

        if (item == null)
        {
            throw new ArgumentNullException(nameof(item));

        _dataStore.RemoveAll(e => e.Id == item.Id);
    }

    public void Save()
    {
        // SAVE TO DB

        Console.WriteLine("Changes saved successfully to the database.");
    }

    public IEnumerable<T> GetAll()

        return _dataStore;
